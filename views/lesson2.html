Lesson 2 - Clickstream Data

Course: Introduction to Learning Analytics

Reading Material

Clickstream data is the trail of actions a user leaves behind while using a website or an app. Each action becomes one row in a table.

A typical row stores the time, who did it, where it happened (the context), which part of the system was involved (the component), what happened (the event name), a short description, the origin (web or mobile) and the IP address.

Moodle, the learning platform used by many universities, stores its logs in exactly this shape. This project copies that idea: every click, page view, video play and quiz answer in this app is written into a SQLite table called clickstream, and you can see it on the Logs page.
